# ToDo

Веб-приложение «ToDo».

При разработке использовалось:

- **React**,
- **Redux Toolkit**
- **TypeScript**,
- **HTML(JSX)**,
- **CSS**.

Возможности веб-приложения:

- Поле для ввода новой задачи;
- Списки задач:
  - общий,
  - невыполненных задач,
  - выполненных задач,
- Количество оставшихся задач;
- Очистка выполненных.

Посмотреть веб-приложение можно по ссылке: [**ToDo**](https://nizovtsev-daniil.github.io/todo/)
